Preguntas frecuentes

Preguntas rápidas

¿Qué necesito para empezar?

Una computadora con Windows y Google Chrome en la caja, un lector de código de barras (si ya tiene uno, sirve) y su certificado de firma electrónica vigente para facturar. Para imprimir tickets, una impresora común o térmica.

¿Funciona si se cae el internet?

Sí. Las ventas se guardan en la computadora de la caja y se sincronizan al volver la conexión. Lo que sí necesita internet: crear o editar productos y ver reportes.

¿Y las facturas del SRI?

Cada venta genera su factura electrónica con el programa de facturación que se instala una sola vez en la computadora de la caja. Si no hay internet, queda pendiente y se emite al volver. El SRI puede rechazar una factura por datos incorrectos; el programa muestra el motivo para corregirla.

¿Sirve para restaurantes?

No, está hecho para comercios que venden productos con código de barras: tiendas, minimarkets, bazares, papelerías, ferreterías.

¿Puedo manejar varias sucursales?

Todavía no. Un plan sirve para una tienda y una caja. Escríbanos si necesita más.

¿Qué pasa con mis datos si dejo de pagar?

Tiene 7 días de gracia; después se bloquea el sistema, pero puede descargar sus datos en CSV. Le avisamos por correo, y sus datos no se borran antes de 90 días después de ese plazo.

¿Cuánto cuesta?
